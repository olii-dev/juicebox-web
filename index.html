A frontend that does the work for you.

Identification by signature

Juicebox reads each file's header, never its name or extension. A probe order built from real cross-detection risks means the right console is picked every time — even for headerless ROMs.

Plays in-app

Bundled libretro cores run every system on a dedicated real-time thread.

Box art from IGDB

Cover art, summary and metadata arrive automatically — a weak match is left unmatched rather than wrong.

Deliberately glossy

A Frutiger Aero interface: skies, reflective glass, wet-floor reflections, hand-drawn gloss.

Rewind & save states

Scrub backwards through recent history. Six save slots with thumbnails, plus quick-resume.

Full controller support

Any MFi controller is detected automatically — DualSense, Xbox, Joy-Cons, 8BitDo. Keyboard and gamepad are both fully remappable per system, and changes apply to a running game without a restart.

Ten screen shaders

From pristine pixels to a full curved CRT with aperture grille and phosphor bloom — swap live.

Cheats, your way

Paste a Game Genie or Game Shark code, or import a .cht file. Toggles apply live.

Questions

Before you ask.

Do I need BIOS files or firmware?

No. Juicebox ships no BIOS and needs none — melonDS falls back to its own FreeBIOS, and PCSX-ReARMed ships an HLE BIOS. Drop in your own dumps for higher accuracy if you like, but it's entirely optional.

Does Juicebox ship ROMs?

No, and it never will. Juicebox indexes ROMs where you already keep them and never moves or copies them unless you ask. It's a frontend, not a source of games.

What about N64 and 3DS?

Both are recognised — drop one in and Juicebox tells you what it is — but not yet playable. They need a hardware-rendered GPU context that the render bridge doesn't provide yet. The detection and header parsing are written and tested, so it's a matter of solving the emulation pipeline, not the formats.

Is it free?

Yes. Juicebox is GPL-3.0 because it bundles libretro cores that are — the same route OpenEmu and RetroArch took. It'll always be free.

What Mac do I need?

macOS 26 (Tahoe) or later, on Apple Silicon. The cores are arm64 and several use dynamic recompilers that want the JIT entitlement.
